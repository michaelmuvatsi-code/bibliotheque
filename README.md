# 📚 Système de Gestion de Bibliothèque

Application web de gestion de bibliothèque développée en **PHP / MySQL** avec une interface utilisateur responsive.

## 🚀 Fonctionnalités

- **Espace Public / Lecteur :**
  - Consultation des ouvrages du catalogue.
  - Recherche dynamique par titre ou auteur.
  - Consultation de la fiche détaillée des livres.
  - Gestion d'une liste de lecture (favoris).

- **Espace Administration :**
  - Authentification sécurisée (mots de passe hachés).
  - Gestion des rôles (`Lecteur` / `Admin`).
  - Gestion CRUD complète du catalogue (Ajouter, Modifier, Supprimer un livre).

- **Interface & Sécurité :**
  - Palette de couleurs moderne (Bleu & Blanc).
  - Menu latéral mobile à 50% de largeur.
  - Validation des formulaires côté client et serveur.
  - Disparition automatique des messages d'alerte (5 sec).

## 🛠️ Technologies utilisées

- **Back-end :** PHP (PDO), MySQL
- **Front-end :** HTML5, CSS3 (Flexbox/Grid, CSS Variables)
- **Scripting :** JavaScript Vanilla
